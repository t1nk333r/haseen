## What changed

- **Names.** Plugin id `haseen.prayers`, display name "Prayers", IPC target
  `haseen.prayers`, notification app name "haseen prayers", state under
  `$XDG_STATE_HOME/haseen/prayers/`, scripts `haseen-prayers-zone.sh` and
  `haseen-prayers-notify.sh`. The engine's provider string reads
  "haseen prayers engine".
- **Manifest.** Native haseen manifest (`plugin.schema.json`) with kinds
  `service`, `bar-widget`, `panel` and role `prayers`. Defaults: Riyadh city
  centre (24.7136, 46.6753), `Asia/Riyadh`, method 4 (Umm al-Qura), English;
  everything else as upstream. `centerOnBar` is dropped: haseen's panel host
  places every panel itself. `debugIpc` is new (test hooks).
- **Structure.** Upstream's `BarWidget.qml` kept a hidden `Panel.qml` alive to
  own the engine. Here `Service.qml` owns the engine, the 30 s tick and the
  notification queue once per shell (bars exist per screen), `Widget.qml` and
  `Panel.qml` read it through `Plugins.roles.prayers`. The four layout files
  (`PanelHorizon`, `PanelCompact`, `PanelDisplay`, `PanelLocation`) are the
  upstream files with `Style`/`Color`/`Util` mapped to `Theme` and the host.
- **Controls.** Omarchy's `qs.Ui` controls (Button, ButtonGroup, ToggleSwitch,
  Dropdown, SearchableDropdown, PanelSlider, NumberField, TextField,
  PanelSectionHeader, PanelToolTip) are replaced by the local `Prayer*.qml`
  files. Dropdowns open inline instead of in a popup window, because a second
  window would break the panel's focus grab.
- **Settings writes.** Upstream wrote through the bar's `updateEntryInline`.
  Here a change goes to `Config.setRuntime` at once and to
  `~/.config/haseen/shell.json` through `haseen-prayers-set.sh`
  (`shell/lib/plugin.sh` helpers).
- **Scripts.** `haseen-prayers-notify.sh` uses `notify-send -a "haseen
  prayers"` instead of `omarchy-notification-send`, goes through `common.sh`
  (`run`, `write_user_file`, `--dry-run`), and stays silent while the haseen
  `dnd` flag is on. `haseen-prayers-zone.sh` no longer creates a state
  directory or deletes upstream's legacy cache files: it writes nothing.
- **Fix.** `PanelCompact.qml` no longer reads `iqama.label` on the Sunrise
  row, whose iqama is null (a TypeError on every open upstream).
- **Keys.** The single-letter shortcuts stay; Tab switching between Omarchy
  panels is gone.
- **Tests.** `tests/Engine.test.js`, `Model.test.js`, `Aladhan.test.js` are
  upstream's pure-JS suites (the `setHostProperty` cases went with the
  function, which only served Omarchy's bar façade). `Riyadh.test.js` is new.
  Upstream's QML lifecycle and network tests (`IpcLifecycle`,
  `PanelLifecycle`, `LocationNetwork`, `EngineQml`, `Scripts`) are not ported:
  they test Omarchy host behaviour; `tests/test-prayers.sh` covers the haseen
  scripts.
