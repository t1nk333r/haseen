# Hyprland (Lua config)

haseen runs Hyprland 0.56+ with a **Lua** config. API reference:
https://wiki.hypr.land/Configuring/Start/

## Who owns which file

| File | Owner | Notes |
|---|---|---|
| `$HASEEN_PATH/default/hypr/init.lua` and `input.lua looknfeel.lua binds.lua windowrules.lua autostart.lua` | haseen (read-only) | defaults, improved by updates |
| `~/.local/state/haseen/current/theme/hyprland.lua` | generated by `haseen theme set` | border colours; never hand-edit |
| `~/.local/state/haseen/current/theme/rounding.lua` | generated by `haseen theme set` | window `rounding` = the shell frame's radius; loads with the defaults |
| `~/.config/hypr/hyprland.lua` | user | seeded once; loads the defaults, then the theme, then the three files below |
| `~/.config/hypr/monitors.lua` | user (create it) | outputs, modes, scale |
| `~/.config/hypr/bindings.lua` | user (create it) | key bindings |
| `~/.config/hypr/local.lua` | user (create it) | everything else: look and feel, input, rules, env, autostart |

Load order (later wins): defaults and the shared window radius → `haseen
toggle`/`haseen hw` state → hyprmod's `~/.config/hypr/hyprland-gui.lua`, when
that GUI settings app is installed → theme (its own `rounding` is ignored) →
`monitors.lua` → `bindings.lua` → `local.lua`. Put changes
in the three optional files rather than in `hyprland.lua`, and never in
`$HASEEN_PATH`. A user file that throws is caught: Hyprland shows the error as
a notification and keeps loading.

## Helpers the defaults define (global table `haseen`)

```lua
haseen.bind(keys, description, dispatcher_or_command, options)  -- string = shell command
haseen.ipc(target, fn, ...)      -- "haseen shell ipc …" command string
haseen.launch(command)           -- "uwsm-app -- command": the app gets its own scope
haseen.include_optional(path)    -- dofile if it exists; errors are reported, not fatal
haseen.path                      -- $HASEEN_PATH
haseen.paths.home / .config_home / .state_home
```

Read `$HASEEN_PATH/default/hypr/binds.lua` for the default keys before you
add one.

## Key bindings (`~/.config/hypr/bindings.lua`)

Hyprland stacks binds: rebinding an existing key without unbinding it first
fires both actions. Unbind with the **exact** key string the default uses.

```lua
-- Replace the default browser key.
hl.unbind("SUPER + B")
haseen.bind("SUPER + B", "Browser", haseen.launch("firefox"))

-- A new key.
haseen.bind("SUPER + E", "Files", haseen.launch("nautilus --new-window"))

-- Open a shell panel plugin.
haseen.bind("SUPER + N", "Notes", haseen.ipc("panel", "toggle", "alice.notes"))
```

Options (4th argument) are Hyprland bind flags, e.g.
`{ locked = true, repeating = true }` (see `binds.lua` for volume keys).
Default shell keys: SUPER+SPACE menu, SUPER+SHIFT+SPACE app launcher,
SUPER+ESCAPE system menu, SUPER+A AI panel, SUPER+CTRL+ESCAPE close panel,
SUPER+CTRL+L lock.

Hyper binds (`SUPER + SHIFT + ALT + CTRL + key`) need keyd: `haseen setup
keyd on` makes holding CapsLock send all four modifiers (tap = Escape,
RightAlt+CapsLock = CapsLock). It is off by default, and the defaults ship
no hyper binds: add your own in `bindings.lua`.

## Monitors (`~/.config/hypr/monitors.lua`)

```lua
hl.monitor({ output = "DP-1", mode = "2560x1440@144", position = "0x0", scale = 1 })
hl.monitor({ output = "eDP-1", mode = "preferred", position = "auto", scale = 1.25 })
```

`hyprctl monitors` lists the output names.

## Everything else (`~/.config/hypr/local.lua`)

```lua
hl.config({
  general = { gaps_in = 2, gaps_out = 2, border_size = 1 },
  decoration = { rounding = 0 },
  input = { kb_layout = "us,de", kb_options = "grp:alt_shift_toggle" },
})

-- Window rules: the native table form. Match strings are RE2 regexes over
-- the WHOLE value, so "firefox" does not match "org.mozilla.firefox".
hl.window_rule({
  name = "user_float_pavucontrol",
  match = { class = "^org\\.pulseaudio\\.pavucontrol$" },
  float = true,
  center = true,
})
```

Keep haseen's look: no blur and no shadows (the defaults turn them off to
save GPU and battery). Do not add them back unless the user asks.

## Apply and verify

```bash
hyprctl reload            # saving also reloads; run it to be sure
hyprctl configerrors      # must print nothing
hyprctl binds -j | jq '.[] | select(.description == "Files")'
hyprctl monitors          # after a monitor change
```

If `configerrors` reports anything, fix it or restore the backup before you
finish.
