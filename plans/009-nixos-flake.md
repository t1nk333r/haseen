  - `vapt.enable` adds podman, distrobox and `hostPackages` (14 curated nixpkgs tools).
  - `gaming.enable` adds steam, gamemode and gamescope (`capSysNice`), and asserts that `haseen.enable` is set.
- `nix/home.nix`: options `haseen.{enable,package,shell.enable,theme,hypr.enable,hypr.extraConfig}`.

  - Every `${haseenPath}/…` that `home.nix` hard-codes must exist in `share/haseen`.
  - `flake.lock` must pin all three inputs.

### Rejected

- **Wrapping the scripts in place in `$out/bin`.** The router reads `# haseen:summary` from the files next to itself, and a wrapper would hide them. The real scripts therefore go in `libexec/haseen`.
- **Passing `services.ollama.acceleration` through.** nixpkgs removed that option.
- **`haseen.theme` defaulting to a name.** That would re-apply the theme on every switch and override `haseen theme set` at runtime. The default is `null`.
- **The `--cmd uwsm start hyprland-uwsm.desktop` greeter command.** That desktop file itself execs `uwsm start`, so the session would be nested.
- **Setting `nixpkgs.config.allowUnfree` from the module.** A module should not change the consumer's nixpkgs config. The README documents the setting instead.
- **A hyprland flake input.** nixpkgs already ships 0.56.2.

### Open risks

- `nix flake check` warns `unknown flake output 'homeManagerModules'`. The name is the community convention and the warning is harmless.
- I evaluated only x86_64-linux; aarch64-linux was skipped by `flake check`.
- I did not test booting: there is no qemu here. The lanzaboote enrollment steps follow upstream docs and are not exercised.
- The NixOS module's systemd user manager PATH for the shell relies on UWSM importing the login environment. I have not tested this in a running session.
- `haseen theme set` calls `gsettings`, `hyprctl` and foot retinting. These come from the system on NixOS (glib for gsettings is not in the wrapper PATH), and failures only warn during activation.
- `flake.lock` pins nixos-unstable, so `nix flake update` can break eval when upstream renames options.
